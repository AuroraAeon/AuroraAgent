# LongCat-2.5-Preview 纯色图像识别缺陷 — 图注与统计说明

## 一句话结论

均匀纯色图像触发 LongCat-2.5-Preview 的系统性颜色误判：**彩色纯色 0/33 全错**且回答坍塌为消色词（40/45 为黑/白/浅粉），**对照组（红底白圆）3/3 正确**，缺陷定位于均匀图像的颜色感知环节，而非图片上传或解码链路。

## 图注（可直接用于论文）

**图 1｜LongCat-2.5-Preview 在均匀纯色图像上的颜色误判具有系统性。**
a，15 个测试刺激（11 个彩色纯色、3 个消色纯色、1 个红底白圆对照组；256 px，红另以 64 px 复测）及其本地生成的原始图像，右侧标注模型在三轮独立请求中的回答与正确次数。b，刺激与实际回答的混淆矩阵；注意对照组列（青框）全部落在"红色"，而彩色纯色列的回答高度集中于"黑色"与"白色"。c，按类别汇总的准确率：彩色纯色 0/33（11 刺激 × 3 轮），消色纯色 5/9，对照组 3/3；散点为逐轮原始结果。误差范围未给出，因三轮回答完全一致的刺激占 11/15，误判呈确定性而非随机波动。

**图 2｜误判是确定性的，且回答向消色系坍塌。**
d，45 次请求的逐轮原始回答（绿色=正确，红色=错误），右列标注该刺激三轮回答是否完全一致；11/15 刺激在三轮中给出逐字相同的回答，表明误判由确定性机制产生，而非采样噪声。e，全部 45 次回答的类别分布，其中 40 次（88.9%）为黑/白/浅粉等消色词，42 次（93.3%）不是该刺激的正确颜色，提示模型在缺乏纹理与边缘信息的均匀图像上回退到了亮度/消色判断。

## 统计说明

- **设计**：15 个刺激 × 3 轮独立请求 = 45 次，全部调用真实 API（`LongCat-2.5-Preview`，默认参数），单轮成本约 ¥0.004，三轮合计约 ¥0.012。
- **分组**：彩色纯色 11 个（红、绿、蓝、黄、紫、橙、青、粉、棕、红@64px、深蓝），消色纯色 3 个（黑、白、灰），对照组 1 个（红底白圆）。
- **主结果**：彩色 0/33、消色 5/9、对照 3/3。
- **Fisher 精确检验（单侧）**：对照组 vs 彩色组 p ≈ 1.4 × 10⁻⁴；消色组 vs 彩色组 p ≈ 1.5 × 10⁻⁴。两者均说明观察到的差距不太可能由随机波动产生。
- **确定性**：11/15 刺激的三轮回答逐字相同（含全部 8 个"答成黑色"的彩色刺激）。
- **链路验证**：对照组（红底白圆）在同一会话、同一上传路径下 3/3 答"红色"，证明图片上传、Base64 编码、上游解码与多模态视觉链路完好；因此缺陷应定位于模型对**均匀、无纹理、无边缘**图像的颜色感知，而非客户端或传输层。
- **复现**：`npm run color`（单轮 15 刺激）；三轮原始数据见 `round1.json` / `round2.json` / `round3.json`，聚合数据见 `color-raw-3rounds.csv` 与 `color-summary-3rounds.csv`。

## 实测建议

涉及颜色判断的场景，应为图像补充参照物、纹理或文字标注，避免直接上传大面积均匀纯色图。
