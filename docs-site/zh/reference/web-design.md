# 网页设计规范（Web Design Spec）

> 本文件是 AuroraAgent 网页工作台（`web-ui/`）视觉与交互的**单一真值源**。新增或改造界面前先读本文件，提交前对照文末「自查清单」。
> 来源：蒸馏 ZCode `DESIGN.md` 中可跨项目复用的部分，落到本项目零依赖 CSS 的实际形态；终端侧的对应规范是 `tui-design.md`，两者互不覆盖。
> 落地模块：`web-ui/src/tokens.css`（设计令牌，双主题）与 `web-ui/src/app.css`（组件样式）。令牌对比度与过渡动画纪律由 `test/guards.mjs` 强制。

---

## 1. 产品气质

界面追求 **calm / dense / operational**（平静、密集、可操作），而不是装饰性。为以下场景设计：

- 长会话：一次任务几十轮工具调用，视觉噪音必须低
- 高信息密度：用文字层级（主 / 次 / 弱）表达密度，而不是靠更多边框与颜色
- 键盘驱动工作流：快捷键是一等交互路径
- 双主题：深色为默认，浅色同名令牌整套覆盖

避免：营销式大间距、大面积品牌色铺底、花哨渐变作为默认语言、背景 / 卡片 / 浮层三者层级暧昧。

## 2. 设计令牌角色表

组件内**禁止硬编码语义色**，一律引用 `tokens.css` 变量；双主题靠 `:root`（深色）与 `:root[data-theme="light"]`（浅色）同名覆盖，组件代码零改动。

| 角色 | 令牌 | 用途 |
| --- | --- | --- |
| 页面 / 工作区底 | `--bg` | 应用最底层背景 |
| 面板 / 侧栏 | `--panel` / `--sidebar-fill` | 结构面；侧栏专用填充与悬停 / 选中两级交互底 |
| 低层容器 | `--surface` / `--surface-hover` | 卡片、输入区等低层级容器表面 |
| 线条 | `--line` / `--line-strong` / `--panel-line` | 默认边框、强边框、面板分隔 |
| 文字主 / 次 / 弱 | `--text` / `--dim` / `--faint` | 正文、元信息、占位与最弱提示 |
| 强调 | `--accent` / `--accent-hi` / `--accent-soft` / `--accent-line` | 唯一强调色来源（取自品牌标识蓝段）；不做大面填充 |
| 语义状态 | `--ok` / `--warn` / `--danger` / `--think`（各带 `-ink` / `-bg` / `-line` 变体） | 成功 / 警告 / 危险 / 思考过程；只用于真实语义，不拿来「让方块更响」 |
| diff 视图 | `--diff-add` / `--diff-del` / `--diff-meta` | 增删行与元信息，不借成功 / 危险色代替 |
| 浮层 | `--tooltip-bg` / `--tooltip-line` / `--tooltip-ink`、`--kbd-bg` / `--kbd-ink`、`--shadow-pop` / `--shadow-card` | 提示气泡、键帽、浮层投影 |

新增颜色必须先成对进双主题，并通过守卫的 WCAG 阈值（正文 ≥ 4.5:1，最弱元信息 ≥ 3.0:1）。

## 3. 排版

- 正文 `15px/1.65` 系统字体栈（`-apple-system` → `PingFang SC` → …）；路径、命令、代码、标识符、快捷键一律等宽。
- 层级靠字重与颜色：标签与标题用 `500`，不上更重的字重。
- 不把「截断」当组件在长文案下唯一生存手段；布局要容忍更长翻译。

## 4. 间距节奏

基频 `4px`，只重复少数几档，不自造任意值：

| 档位 | 用途 |
| --- | --- |
| `4px` | 图标与文字紧贴间距 |
| `8px` | 控件内距与行内 gap |
| `12px` | 密集列表行、菜单行 |
| `16px` | 卡片与面板标准内距 |
| `20px`–`24px` | 大区分隔与弹层内部 |

## 5. 图标与控件尺寸

- **图标基准 `16px`**；工具栏次级图标可用 `13`–`15px`，但同屏保持一致。
- 控件高度三档为主：`28px`（图标钮 / 紧凑控件）、`32px`（列表行）、`36px`（区头）；主按钮 `38px`。复用既有档位，不建新高度体系。
- 图标钮保持方形；不把每个操作都升格成主按钮，面板内动作层级要清晰。

## 6. 圆角层级

按**可见圆容器的嵌套**递减，不按组件重要性：

- 容器：`14px`（`--radius`）→ `12px` → `10px` → `8px` → `6px` → `4px`
- 弹层（对话框 / 菜单 / 提示气泡）不超过 `14px`：气泡与菜单壳 `8px`，键帽与行内小件 `6px`
- `99px` / `999px` 只留给胶囊与圆形；按钮、标签、计数器不因其组件类型就用全圆角

## 7. 浮层与投影

层级优先靠**背景对比与边框**建立，投影克制：菜单 / tooltip / 弹层用 `--shadow-pop`，普通卡片用 `--shadow-card`；不为常规布局加大而软的阴影。浮层表面（`--tooltip-bg` 等）必须安静地压在内容之上、不与卡片背景混层。

## 8. 动效

- 只过渡**颜色 / 透明度 / 变换**；时长三档 `120ms` / `150ms` / `180ms`，曲线统一 `--ease`。
- 浮层进场用 `@starting-style`（淡入 + 轻微缩放，`120ms`）；`prefers-reduced-motion: reduce` 时关闭。
- **禁止 `transition:all`**（守卫强制）。ZCode 教训：大会话 / 连续交互里它会批量启动滚动条色、尺寸等非合成动画，放大主线程 style / layout 压力。
- 动效用于澄清状态变化，不装饰屏幕。

## 9. 菜单与 tooltip 密度语言

提示气泡规格（复刻 ZCode `ControlHintTooltip`，零依赖实现在 `ControlTooltip.tsx` + `.ct-tip`）：

| 部件 | 规格 |
| --- | --- |
| 气泡壳 | 圆角 `8px`、`1px` `--tooltip-line` 边框、`--tooltip-bg` 底、`--shadow-pop` |
| 内距 | 左右 `10px` / 上下 `4px`；带快捷键键帽时右侧收至 `4px`；带描述文案时 `12px` / `8px` |
| 标题 | `12px` / `500`，与快捷键间距 `8px`（带描述时 `6px`） |
| 键帽 `kbd` | 高 `16px`、圆角 `6px`、左右 `6px`、`10px` / `500`、`--kbd-bg` / `--kbd-ink`；非 Apple 平台用等宽，Apple 平台用系统字体 |
| 行为 | hover / focus **即时显示**（无延迟）、`120ms` 淡入缩放、`Esc` 或失焦关闭、滚动与 resize 期间重定位、同时只开一个 |

菜单：紧凑行、`8px` 圆角壳、行悬停 / 选中用低对比填充；相邻选项行固定小间距；子菜单是独立浮层，壳圆角不继承触发器。

## 10. 可访问性与长文案

- 键盘是一等路径：全局快捷键（`Ctrl/Cmd+K` 新建会话、`Ctrl/Cmd+B` 折叠 / 展开侧栏、`/` 聚焦输入框），焦点环统一 `:focus-visible`。
- 语义状态色必须配可读文字，不单靠颜色传达状态。
- 布局容忍长翻译与窄窗口；图标优先配文字标签（tooltip 承担无标签处的说明）。
- 产品内**零 emoji**，图标一律内联 SVG 或 `public/vendors/*.svg`（守卫强制）。

## 11. 新增 / 改造界面自查清单

- [ ] 新颜色进了 `tokens.css` 双主题，且通过对比度守卫（正文 4.5 / 弱信息 3.0）。
- [ ] 组件内无硬编码语义色，全部引用令牌变量。
- [ ] 间距取自 4 / 8 / 12 / 16 / 20–24 档位，图标基准 `16px`，控件高度 28 / 32 / 36 / 38。
- [ ] 圆角按可见容器嵌套递减，弹层不超过 `14px`，全圆角只给胶囊与圆形。
- [ ] 过渡只动颜色 / 透明度 / 变换，无 `transition:all`；`prefers-reduced-motion` 已考虑。
- [ ] 浮层用 `--shadow-pop`，层级靠背景对比优先。
- [ ] 键盘可完成全部操作；图标钮有 tooltip 或文字标签。
- [ ] 双主题下都看过实际效果（守卫只查令牌，不查布局）。
