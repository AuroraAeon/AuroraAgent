# 会话全文检索

侧栏搜索框同时搜会话标题与转录全文（用户消息、助手回复、思考过程、工具调用与结果）。中文会话按二元分词索引，敲两个字也能命中。

## 分词与排序

- 分词：CJK 连续段切二元 gram，拉丁段按词小写——中文会话若整句索引，用户敲两个字永远搜不中；引第三方分词库则破零依赖底线，故自实现
- 排序：Okapi BM25 自实现——长文档不靠篇幅刷分；同分按会话 id 稳定，翻页结果可复现
- 工具结果截断到 4000 字符参与索引：那是给模型看的，不是给人搜的
- 命中片段按需读文件产出（上限 160 字符），内存里不常驻转录原文

## 增量索引

索引是内存倒排索引，不落盘——转录动辄数百 KB，把词频表序列化会得到几十 MB 的文件，每次追加都全量重写，比搜索本身更贵。

- 会话写入时经观察者增量更新：追加只把新记录的文本并进去（不重读整个转录）；替换 / 派生 / 改名按文件重建；删除摘掉
- 只有 `(mtimeMs, size)` 指纹变了的会话才重新分词，未变的会话零成本
- 每 5 分钟一次对账兜底：fork、外部改写、删除都靠它发现
- 终端客户端不传观察者，零开销

## HTTP API

| 方法与路径 | 作用 |
| --- | --- |
| `GET /api/sessions/search?q=` | 全文检索；`q` 上限 200 字符，最多回 20 条命中（带相关度分数与原文片段）。`/api/agent/sessions/search` 同义 |

缺查询词回 400。结果带会话元信息（标题 / 更新时间等），前端直接渲染进侧栏。
