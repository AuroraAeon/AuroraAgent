# 术语与文案规约（Terminology & Copy）

> 本页是 AuroraAgent 领域词汇与面向用户文案的**完整单一事实源**：写文档、写界面文案、写错误消息前先对照。`AGENTS.md`（文档站写作规约）里的术语简表与本页一致。
> 词汇纪律移植自 ZCode `CONTEXT.md`：每个核心概念只有**一个**名字，附 Avoid 清单；自造同义词视为缺陷而非风格问题。

---

## 2. 文案规约

- **错误消息 = 原因 + 下一步**：说清为什么，并告诉用户做什么。例：「API Key 无效（401）：请到设置页「通用」面板重新填写」；不写「认证失败」。
- **提示与标签 = 动词开头的短标签**：按钮与菜单项用动作命名（「切换侧边栏」「新建会话」）；状态用名词（「生成中」「等待授权」）。
- **单位口语化**：用量写 `13K / 50K`、时长写 `2min30s`，面向用户不讲「token 化」「字符级」这类实现术语。
- **零 emoji**：界面、错误消息、终端 banner 都不出现 emoji；图标一律内联 SVG 或 `public/vendors/*.svg`。
- **中英一致**：同一概念在中英页面用词统一，按本页英文列书写；英文页允许按表达习惯重组句子，不改概念名。
- **终端特例**：`Esc cancel`、`y/n/a` 等命令行惯例属 TUI 规范（`tui-design.md`），不适用本页短标签规则。

## 3. 示例对照

| 场景 | 这样写 | 不要这样写 |
| --- | --- | --- |
| 401 上游拒绝 | API Key 无效（401）：请到设置页「通用」面板重新填写 | 认证失败 / unauthorized |
| 折叠侧栏 tooltip | 切换侧边栏 + `⌘B`（非 Apple 平台 `Ctrl+B`） | 收起侧栏 / 展开侧栏 |
| 故障转移提示 | 主提供方返回 429，已切换到「XX」重试 | 正在换路 / retrying |
| 预算触顶 | 目标预算已用完，已收尾；可 `/goal budget` 调整 | budget exceeded |
| 空会话列表 | 还没有会话，发第一条消息开始 | 无数据 / empty |
