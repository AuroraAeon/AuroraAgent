# 技能系统

技能 = 一个带 YAML frontmatter 的 Markdown 文件：`name` + `description` + 正文。目录清单（仅名称与描述）常驻系统提示；正文在被调用时按需加载——不占日常上下文。

## 调用方式

1. **显式**：任意客户端输入 `/<技能名> [参数]`（终端命令、网页输入区 `/` 调色板同源；服务端单点解析）
2. **隐式**：模型判断用户请求与某技能描述匹配时，自行调用 `skill` 工具

## 存放位置

| 位置 | 来源 | 说明 |
| --- | --- | --- |
| `skills/` | 内置 | 随仓库分发，当前 4 个 |
| `<数据目录>/skills/` | 用户 | 自定义技能，重启后生效 |

## 编写一个技能

````markdown
---
name: my-skill
description: 一句话说明何时该用这个技能（模型只看这句）
---

# 规则

- 第一条规范

# 工作流

1. 第一步
2. 第二步

# 禁止

- 不要做的事
````

写描述时想象「模型只读这一句话来决定是否调用」——具体、可判断。
