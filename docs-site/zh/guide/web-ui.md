# 网页工作台

`npm run web` 后访问 `http://localhost:8787`（React 19 + Vite 7 + TypeScript，源码在 `web-ui/`，构建产物随仓库提交在 `public/app/`，运行时零构建）。

## 界面分区

- **侧栏**（像素级对齐 dsh web）：品牌（点按即新建会话）、新会话钮、会话列表（32px 行：标题 + 相对时间，悬停现出派生 / 删除操作，区头搜索实时过滤；行首槽位在会话运行中转灰色加载圈）、可整块收起（偏好本机记忆：收回后左侧边完全消失，只留常驻的顶部浮层与 Header，200ms 擦除动画；切换 / 后退 / 前进 / 新建 / 更新入口都在浮层上）、设置入口（模式切换在输入区）；新会话首条消息发出后，标题按消息内容自动总结更新（默认本地推导，不调模型；也可在输入区切「模型总结」——每个新会话多一次小额请求，失败自动回退；手动改名过的会话不被覆盖）
- **工作区 Header**（复刻 ZCode WorkspaceHeader，常驻 48px）：工作区上下文钮（hover 即显信息卡、点击钉住——工作目录 home 缩写 / 最近活动 / git 分支）、会话标题（14px/600，双击原位重命名，Enter 提交 / Esc 取消）、更多菜单（重命名 / 复制会话 ID / 复制工作目录 / 派生 / 删除）、帮助菜单（使用文档 / 反馈问题外链 + 快捷键与关于两个信息面板）、设置入口；侧栏收回时内行加左侧内距，给顶部浮层让位
- **对话区**：用户消息、流式回答（带活动状态行：轮次 / 工具数 / 走秒）、可折叠思考块、工具调用摘要行（无框单行：图标 / 类别 / 资源 / 状态，参数 / 结果 / diff / 待办默认收起，点开落面板）、内联权限卡、计划卡、每轮用量脚注
- **输入区**：自适应文本框、「添加上下文」加号菜单（上传本机文本文件——内容以 `<file name>` 块插入输入框供模型读取；或引用工作目录文件）、`/` 斜杠命令菜单（命令与技能合并，随输入实时过滤：无参数命令回车即执行、带参数命令补全续写，合法 / 未知命令有色彩语义提示）、`/goal` 目标命令（与终端同解析，详见 [Goal 模式指南](/zh/guide/goal-mode)）、Harness 切换、权限三档下拉、标题生成方式（本地总结 / 模型总结）、模型选择器（按提供方分组；二级菜单内含思考强度：标准 / 关闭，会话级）；计划模式开关已并入 `/plan` 命令，开启后输入区显示状态芯片
- **回合导航**（复刻 ZCode ConversationTurnNavigator）：对话区左缘的离散「梯状」历史轨，每个用户提问一条 10px 短棒。悬停某条时以它为山峰向上下衰减（不透明度 + 横向缩放），右侧浮出预览卡（提问摘录 + 助手回复摘录）；点击平滑跳转到对应提问，滚动位置驱动高亮「当前读到哪一问」。少于 2 问不出现，会话区窄于 864px 整体隐藏；同一轮里连发的多条提问共享该轮的助手摘录
- **侧边对话**（`/btw <问题>`）：一问一答的临时分支，继承当前会话历史，不落盘、不进会话列表、不接管目标；输入框上方显示侧边横幅（返回主对话 / 丢弃），`Ctrl+/` 主 / 侧边切换（与终端同键位）
- **目标条**（有目标时单行停靠在输入框上方）：状态芯片、目标内容、tokens / 轮次 / live 时长、预算上限、验证结论芯片与暂停 / 恢复 / 停止按钮；目标完成即隐藏，回执走消息流

## 设计纪律

- 视觉与交互的完整规范（令牌角色表 / 间距节奏 / 圆角层级 / 动效纪律 / tooltip 密度）见[网页设计规范](/zh/reference/web-design)；领域词汇与文案写法见[术语与文案规约](/zh/reference/terminology)
- 设计令牌集中在 `web-ui/src/tokens.css`：组件内禁止硬编码语义色；diff / 成功 / 危险 / 思考各有专属令牌
- **零 emoji**，图标一律内联 SVG（`web-ui/src/icons.tsx`）
- 不引 CDN、不引 Markdown / 状态管理等第三方库；动画用原生 CSS
- Markdown 为手写子集渲染器；代码块走零依赖语法高亮器（`web-ui/src/highlight.ts`，拼接恒等无损）
- LaTeX 公式经 KaTeX 自托管渲染（`trust: false`，`\href` / `\includegraphics` / HTML 扩展一律拒绝，解析失败回退展示原始源码）

## 设置弹层

左侧分类导航（通用 / 提供方 / 故障转移 / 网络 / 技能 / MCP 工具 / 终端 / 用量 / 错误日志）——每个分区首次进入才加载，切回保留未保存的草稿；行式条目（标题 + 说明 + 右侧控件）。提供方管理（自定义上游）、技能目录、MCP 服务器管理（实验特性）、开机自启开关、数据目录与版本。
