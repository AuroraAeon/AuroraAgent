# 网页工作台

`npm run web` 后访问 `http://localhost:8787`（React 19 + Vite 7 + TypeScript，源码在 `web-ui/`，构建产物随仓库提交在 `public/app/`，运行时零构建）。

## 界面分区

- **侧栏**：品牌、新建会话、会话列表（相对时间 + 模式 + 轮次）、设置入口；新会话首条消息发出后，标题按消息内容自动总结更新（默认本地推导，不调模型；也可在输入区切「模型总结」——每个新会话多一次小额请求，失败自动回退；手动改名过的会话不被覆盖）
- **对话区**：用户消息、流式回答（带活动状态行：轮次 / 工具数 / 走秒）、可折叠思考块、工具卡片（状态 / 参数 / 结果 / diff / 待办）、内联权限卡、计划卡、每轮用量脚注
- **输入区**：自适应文本框、`/` 技能调色板、思考开关、Harness 切换、权限三档下拉、计划模式开关、标题生成方式（本地总结 / 模型总结）、模型选择器（按提供方分组）

## 设计纪律

- 设计令牌集中在 `web-ui/src/tokens.css`：组件内禁止硬编码语义色；diff / 成功 / 危险 / 思考各有专属令牌
- **零 emoji**，图标一律内联 SVG（`web-ui/src/icons.tsx`）
- 不引 CDN、不引 Markdown / 状态管理等第三方库；动画用原生 CSS
- Markdown 为手写子集渲染器；代码块走零依赖语法高亮器（`web-ui/src/highlight.ts`，拼接恒等无损）
- LaTeX 公式经 KaTeX 自托管渲染（`trust: false`，`\href` / `\includegraphics` / HTML 扩展一律拒绝，解析失败回退展示原始源码）

## 设置弹层

提供方管理（自定义上游）、技能目录、MCP 服务器管理（实验特性）、开机自启开关、数据目录与版本。
